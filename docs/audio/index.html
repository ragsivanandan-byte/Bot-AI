Ajoutez une vidéo de leçon (ou un fichier audio) : l'audio est extrait sur l'iPhone, puis reste disponible sans connexion.

      Où trouver la vidéo ?

      • Raccourci « Leçon en audio » : fichier dans Fichiers › Sur mon iPhone › a-Shell › Lecons-Audio → « Choisir un fichier ».
      • Enregistrement de l'écran : « Photothèque » (ou mieux : enregistrez-le d'abord dans Fichiers pour éviter la compression).
      • Fichier reçu par AirDrop ou téléchargé : « Choisir un fichier ».

      Tout se fait sur l'iPhone : rien n'est envoyé sur Internet.

      Trois étapes : 1 récupérer la vidéo (ou directement son audio) de la leçon, 2 l'ajouter ici, 3 écouter, même en mode Avion.

      ① Installer Leçons Audio sur l'écran d'accueil
      1. Ouvrez cette page dans Safari.
      2. Touchez → Sur l'écran d'accueil → Ajouter.
      3. Lancez désormais l'app depuis son icône : elle fonctionne sans connexion.
      ② Méthode recommandée : le raccourci « Leçon en audio »

      Depuis la page de la leçon dans Safari, un seul geste télécharge uniquement la piste audio (rapide et léger, même pour une vidéo de 2 h). Il utilise l'app gratuite a-Shell et l'outil libre yt-dlp.

      Installation (une seule fois, ~5 min)

      1. Installez a-Shell (gratuit) depuis l'App Store, ouvrez-le et tapez :
        pip install yt-dlp
      2. Réglages de l'iPhone → Apps → Raccourcis → Avancé → activez Autoriser l'exécution de scripts (iOS 17 et avant : Réglages → Raccourcis → Avancé).
      3. App Raccourcis → ＋ → nommez le raccourci Leçon en audio.
      4. Touchez ⓘ (Détails) → activez Afficher dans la feuille de partage. Dans le bloc « Recevoir … de Feuille de partage », ne gardez que Pages web Safari.
      5. Ajoutez l'action Exécuter du JavaScript sur une page web (tapez « JavaScript » dans la recherche d'actions ; entrée : Entrée du raccourci). Effacez son code d'exemple et collez ce script :
        Voir le script
        Chargement…
      6. Ajoutez l'action Execute Command d'a-Shell (cherchez « a-Shell »). Dans son champ de commandes, insérez la variable produite par l'action précédente (Résultat JavaScript), et rien d'autre. Si l'action propose de s'exécuter dans l'app (« Open a-Shell »), activez-le : les longs téléchargements y sont plus fiables.

      Utilisation

      1. Ouvrez la leçon dans Safari (connecté à l'Académie) et attendez que la vidéo s'affiche.
      2. Touchez → Leçon en audio. a-Shell s'ouvre et affiche la progression.
      3. Ici : Ajouter → Choisir un fichier → Sur mon iPhone › a-Shell › Lecons-Audio.

      Le fichier prend le nom de la leçon (ex. 2026-09-20-bitcoin-talk-life-discord.m4a ; l'extension peut être .mp4 : c'est quand même l'audio seul). Il est lisible tel quel dans Fichiers ; l'ajouter ici donne en plus la reprise de lecture, la vitesse et les contrôles sur l'écran verrouillé.

      ③ Sans aucune app : l'enregistrement de l'écran

      Fonctionne avec n'importe quel lecteur vidéo, mais en temps réel (1 h de vidéo = 1 h d'enregistrement).

      1. Ajoutez Enregistrement de l'écran au Centre de contrôle (Réglages → Centre de contrôle).
      2. Activez Ne pas déranger et réglez le verrouillage auto sur Jamais le temps de l'enregistrement.
      3. Laissez le micro désactivé (appui long sur le bouton d'enregistrement) : seul le son de la vidéo sera capté.
      4. Lancez la vidéo de la leçon, démarrez l'enregistrement de l'écran, laissez jouer jusqu'au bout, puis arrêtez.
      5. Dans Photos : Partager → Enregistrer dans Fichiers (évite la compression), puis ici : Ajouter → Choisir un fichier. Vous pouvez ensuite supprimer la vidéo de Photos.
      ④ Écouter hors ligne et sauvegarder
      • Les leçons ajoutées sont stockées dans l'app, sur l'iPhone : aucune connexion nécessaire.
      • Lecture en arrière-plan et écran verrouillé, −15 s / +30 s, vitesse 0,75× à 2×, reprise automatique là où vous vous êtes arrêté.
      • Menu ⋯ d'une leçon → Enregistrer dans Fichiers pour en garder une copie (iCloud Drive, ou pour l'écouter dans une autre app comme VLC).
      Dépannage
      • « Aucune video trouvee » : lancez la lecture de la vidéo, attendez quelques secondes, relancez le raccourci.
      • Erreur yt-dlp (403, « Unable to extract »…) : dans a-Shell, mettez à jour avec pip install -U yt-dlp puis réessayez.
      • « Aucune piste audio » : la vidéo n'a pas de son (enregistrement d'écran fait volume coupé ?).
      • Format non pris en charge : seuls MP4/MOV/M4V (et MP3/M4A) sont acceptés.
      • La bibliothèque a disparu ? Vous êtes peut-être dans Safari au lieu de l'icône (bibliothèques séparées).

      Usage personnel : respectez les conditions de l'Académie et ne partagez pas les enregistrements.
