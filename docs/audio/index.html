      Trois étapes : 1 récupérer la vidéo (ou directement son audio) de la leçon, 2 l'ajouter ici, 3 écouter, même en mode Avion.

      ① Installer Leçons Audio sur l'écran d'accueil
      1. Ouvrez cette page dans Safari.
      2. Touchez → Sur l'écran d'accueil → Ajouter.
      3. Lancez désormais l'app depuis son icône : elle fonctionne sans connexion.
      ② Méthode recommandée : le raccourci « Leçon en audio »

      Depuis la page de la leçon dans Safari, un seul geste télécharge uniquement la piste audio (environ 3 min pour une leçon de 2 h). Il utilise deux apps gratuites, a-Shell et Raccourcis (Apple), et l'outil libre yt-dlp.

      A. Préparer les apps (une seule fois)

      1. Dans l'App Store, installez a-Shell, ainsi que Raccourcis d'Apple si elle n'est pas sur votre iPhone (elle a pu être supprimée).
      2. Ouvrez a-Shell, tapez cette commande puis Entrée, et attendez le retour du $ :
        pip install yt-dlp
      3. Réglages → tout en bas Apps → Raccourcis → Avancé → activez Autoriser l'exécution des scripts. La recherche des Réglages ne trouve pas cette option : passez par ce chemin. Si « Raccourcis » manque dans la liste des apps, c'est qu'elle n'est pas installée (étape 1).

      B. Créer le raccourci (une seule fois, ~5 min)

      1. App Raccourcis → ＋ en haut à droite.
      2. Touchez « Nouv. raccourci ⌄ » en haut → Renommer → Leçon en audio.
      3. Touchez Rechercher des actions, tapez JavaScript et choisissez Exécuter JavaScript sur une page web.
      4. Touchez ⓘ en bas de l'écran → activez Dans la feuille de partage → ✓. Un bloc « Recevoir … depuis Feuille partagée » apparaît en haut : touchez le mot bleu après « Recevoir » et ne cochez que Pages web Safari.
      5. Dans l'action JavaScript, touchez le mot bleu « Page web » → Entrée de raccourci.
      6. Copiez le script avec ce bouton, puis dans l'action : appui long dans le code d'exemple → Tout sélectionner → Coller. Le code doit commencer par // Leçons Audio.
        Voir le script
        Chargement…
      7. Recherchez a-Shell dans les actions et choisissez Execute Command (affichée « Exécuter »). Elle doit indiquer « Exécuter Résultat JavaScript » ; sinon, touchez son champ et choisissez cette variable au-dessus du clavier.
      8. Touchez la petite flèche de l'action a-Shell → Ouvrir l'application ? : choisissez l'option qui ouvre toujours a-Shell. Laissez « Continuer après une erreur » désactivé.
      9. Touchez < en haut à gauche (enregistrement automatique), puis redémarrez l'iPhone : iOS n'ajoute souvent le raccourci au bouton Partager qu'après un redémarrage.

      C. Pour chaque leçon

      1. Ouvrez la leçon dans Safari (connecté à l'Académie) et attendez que la vidéo s'affiche.
      2. Partager (parfois dans le menu •••) → faites défiler → Leçon en audio. La première fois, répondez Toujours autoriser. Astuce : en bas de cette liste, « Modifier les actions… » → ＋ vert sur « Leçon en audio » pour l'avoir tout en haut.
      3. a-Shell s'ouvre et télécharge : restez dedans, écran allumé, jusqu'à 100% et le retour du $.
      4. Ici : Ajouter → Choisir un fichier → Sur mon iPhone › a-Shell › Lecons-Audio → le fichier, puis attendez « ✓ Ajoutée ».
      5. Supprimez ensuite le fichier du dossier a-Shell (appui long → Supprimer) : l'app garde sa propre copie.

      Le fichier porte le nom de la leçon (ex. 2026-09-20-bitcoin-talk-life-discord.mp4) : même en .mp4, c'est bien l'audio seul.

      ③ Sans aucune app : l'enregistrement de l'écran

      Fonctionne avec n'importe quel lecteur vidéo, mais en temps réel (1 h de vidéo = 1 h d'enregistrement).

      1. Ajoutez Enregistrement de l'écran au Centre de contrôle (Réglages → Centre de contrôle).
      2. Activez Ne pas déranger et réglez le verrouillage auto sur Jamais le temps de l'enregistrement.
      3. Laissez le micro désactivé (appui long sur le bouton d'enregistrement) : seul le son de la vidéo sera capté.
      4. Lancez la vidéo de la leçon, démarrez l'enregistrement de l'écran, laissez jouer jusqu'au bout, puis arrêtez.
      5. Dans Photos : Partager → Enregistrer dans Fichiers (évite la compression), puis ici : Ajouter → Choisir un fichier. Vous pouvez ensuite supprimer la vidéo de Photos.
      ④ Écouter hors ligne et sauvegarder
      • Les leçons ajoutées sont stockées dans l'app, sur l'iPhone : aucune connexion nécessaire.
      • Lecture en arrière-plan et écran verrouillé, −15 s / +30 s, vitesse 0,75× à 2×, reprise automatique là où vous vous êtes arrêté.
      • Minuterie de sommeil : le bouton lune du lecteur arrête la lecture après 15, 30, 45, 60 ou 90 min d'écoute (touchez-le plusieurs fois pour choisir ; les pauses ne comptent pas).
      • Menu ⋯ d'une leçon → Enregistrer dans Fichiers pour en garder une copie (iCloud Drive, ou pour l'écouter dans une autre app comme VLC).
      Dépannage
      • « Leçon en audio » absent du bouton Partager : redémarrez l'iPhone ; vérifiez dans Raccourcis → le raccourci → ⓘ que « Dans la feuille de partage » est activé, et que la page est ouverte dans Safari.
      • Réglage « Autoriser l'exécution des scripts » introuvable : installez l'app Raccourcis d'Apple.
      • Mise à jour de cette app : fermez-la complètement puis rouvrez-la (deux fois si besoin) ; le numéro de version est en bas de l'onglet Ajouter.
      • « Aucune video trouvee » : lancez la lecture de la vidéo, attendez quelques secondes, relancez le raccourci.
      • Erreur yt-dlp (403, « Unable to extract »…) : dans a-Shell, mettez à jour avec pip install -U yt-dlp puis réessayez.
      • « Aucune piste audio » : la vidéo n'a pas de son (enregistrement d'écran fait volume coupé ?).
      • Format non pris en charge : seuls MP4/MOV/M4V (et MP3/M4A) sont acceptés.
      • La bibliothèque a disparu ? Vous êtes peut-être dans Safari au lieu de l'icône (bibliothèques séparées).
